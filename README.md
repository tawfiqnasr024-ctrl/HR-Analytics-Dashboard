**HR Analytics Dashboard**
**Project Overview**
This Power BI dashboard was developed to analyze workforce data and provide actionable HR insights for management.

**Business Problem**
Human Resources departments often struggle to monitor employee performance, promotions, attrition, and workforce demographics. This dashboard centralizes key HR metrics to support data-driven decision-making.

**Tools Used**
- Power BI
- Excel
- DAX
- Power Query

**Key Performance Indicators (KPIs)**
- Total Employees
- Gender Distribution
- Employee Attrition Rate
- Promotion Analysis
- Employees Due for Promotion
- Employees Eligible for Retrenchment
- Years of Service Analysis

**Dashboard Features**
- Workforce Overview
- Employee Demographics Analysis
- Promotion Tracking
- Attrition Monitoring
- Service Years Analysis
- HR Performance Insights

**Business Impact**
The dashboard helps HR managers identify workforce trends, monitor employee development, and make informed strategic decisions regarding promotions and workforce planning.

**Skills Demonstrated**
- Data Cleaning
- Data Modeling
- DAX Measures
- Interactive Dashboard Design
- Business Intelligence Reporting
